# 선익시스템 상승 삼각형 누락 수정

기준: 171090, 2026-09-30까지 운영 data 브랜치의 일봉 263개.
재현 데이터: `batch/tests/fixtures/171090_triangle.csv`.

## 원인

- 8월 7일 73,100원과 8월 31일 74,200원의 차이는 1,100원이지만, 두 점의 일일 기울기는 0.103~0.109%로 기존 수평 한계 0.10%를 넘었다. 고점 간 기울기를 첫 저점까지 연장해 계산한 가격 변화량도 수평 한계를 초과했다.
- 기존 minor 스윙의 2 ATR 반전 조건은 9월의 작은 수렴 파동을 놓쳤다. 마지막 고점도 아직 미확정이라 최근 저점·고점 조합이 후보가 되지 않았다.
- 수평 조건만 완화하면 7월 말부터 그린 가파른 지지선이 9월 14일 무효화된다. 이 후보의 기록이 이후 새 고점·저점으로 성립하는 삼각형까지 중복으로 제거했다.

## 수정

- 상승 삼각형에 한정해 1 ATR / 최소 3% 반전의 보조 스윙을 탐색한다. 미확정 극점은 사용하지 않는다.
- 실제 고점들이 만드는 수평 저항대를 추가 평가한다. 폭은 가격의 3%와 0.75 ATR 중 작은 값으로 제한하고, 개별 접촉은 기존 0.5 ATR 기준을 유지한다. 고점 접촉은 구조 기간의 절반 이상에 분포해야 한다.
- 이전 후보가 종료된 시점 이후 새로운 상단·하단 접점이 모두 확인되면 별도의 새 구조를 허용한다. 같은 앵커만 다시 연결하거나 한쪽 접점만 바뀐 경우에는 여전히 제외한다.
- 기존 선 고정, 20~200봉, 상승 지지선, 수렴도, 캔들 포함률, 하단 이탈 및 종가 돌파 확인 조건은 유지한다. 다른 패턴의 스윙 기준은 변경하지 않는다.

## 결과와 확인

- 선익시스템은 7월 29일~9월 15일 구조를 9월 16일부터 인식한다. 9월 30일 현재 저항 74,200원, 지지선 약 69,191원, 종가 69,700원으로 **상승 삼각형 형성 중**이다. 현재 데이터를 돌파 완료로 표시하지 않는다.
- 실제 데이터의 과거 시점 재생, 고정된 선에서의 가상 종가 돌파, 윗꼬리만 넘은 경우, 하단 이탈, 새 양쪽 접점이 필요한 재등록을 회귀 테스트로 추가했다.
- `python scripts/preview_sunic_triangle.py`로 변경 전·후와 명시적인 가상 돌파 예시를 `_workspace/sunic-triangle-review.html`에 생성한다.
- 로컬 알고리즘 변경이다. 운영 반영에는 소스 배포와 패턴 배치 재계산이 필요하다.
