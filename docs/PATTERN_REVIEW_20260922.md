# 패턴별 누락 조건 점검

운영 반영 전 로컬 검토 기록. 모든 조건을 일괄 완화하지 않고 구조를 설명하지 못하는 기간·접점 제약을 우선 조정했다. 최소 20봉, 최대 200봉, 확정된 스윙 사용, 실제 가격 이탈 검사와 형상 점수 필터는 유지한다. 패턴 특성에 따른 최소 길이(라운드 60봉 등)는 유지한다.

| 계열 | 조치 |
|---|---|
| 상승·하락 삼각형 | 고점 2회·저점 2회 접촉 허용. 하루당 고정 기울기 대신 전체 구간에서 1% 및 1 ATR 이상의 유의미한 상승/하락을 요구한다. 수평 경계·수렴은 계속 필수다. |
| 대칭 삼각형 | 양쪽 각 2회 접촉 및 기간 전체의 유의미한 수렴으로 판정한다. 상향·하향 돌파 모두 추적한다. |
| 수렴 쐐기·브로드닝 | 양쪽 각 2회 이상, 합계 5회 이상 접촉은 필수. 접점 분포는 점수로 평가하고, 구조 안쪽의 새로운 스윙이 선에 안 닿는다는 이유만으로 폐기하지 않는다. 기울기·수렴/확대·가격 포함률·형상 필터는 유지한다. |
| 추세선 패턴 공통 | 단기/장기 스윙 모두 20~200봉 탐색. 예상 방향의 첫 돌파가 아직 미확정이면 형성 중으로 유지한다. 반대 방향 이탈 대기는 표시하지 않는다. 확정된 선을 이후 봉에 맞춰 움직이지 않는다. |
| 쌍바닥·쌍봉 | 단기 스윙의 90봉 상한을 200봉으로 확장. 가격 유사성·중간 반등/조정 깊이·넥라인 및 무효화는 유지한다. |
| H&S·역H&S | 단기 스윙의 141봉 상한을 200봉으로 확장. 어깨 유사성·머리 돌출·넥라인 조건은 유지한다. |
| 삼중 바닥·천장 | 두 스케일 모두 구조 기간 20~200봉. 극점 유사성·반등 깊이·돌파/무효화는 유지한다. |
| 라운드 바텀·탑 | 바닥/천장 위치 20~80% 허용 및 좌우 시간 정규화로 비대칭 회복 지원. 단일 꼬리에 의한 바닥권 체류 오판 보완. 깊이·체류·곡률·회복 기준 유지. |
| 상승·하락 플래그 | 변경 없음. 기존 실제 조정 20봉 조건은 사용자가 요청한 최소 기간과 일치한다. 깃대·되돌림·조정 방향·미래참조 방지 조건 유지. |
| 다이아몬드 탑 | 반쪽 기간 후보 20/30/40봉에서 20/25/30/35/40봉으로 확장. 확대 후 수렴·고점·끝점 유사성·돌파/무효화는 유지. 비대칭 마름모 전용 탐지는 이번 범위에 포함하지 않는다. |

## 검토 방법과 한계

- `scripts/preview_remaining_patterns.py`: 17개 상승/하락 결과 유형의 합성 예시를 생성한다. 각 항목에서 형성 중과 돌파 완료를 비교한다.
- `batch/tests/test_remaining_patterns.py`: 각 유형의 형성 중, 확정일 당시 동일한 돌파 인식, 반대 이탈 제외, 긴 단기 스윙 구조를 검증한다.
- 기존 테스트와 앞선 상승 삼각형·컵앤핸들·실제 SK하이닉스 확대 쐐기 회귀 검증도 함께 실행한다.
- 합성 예시 통과는 실제 시장의 누락률·오탐률 개선을 보장하지 않는다. 완화로 후보가 늘 수 있으므로 실제 종목 차트 확인 후 반영한다.
- 커밋·푸시·수동 배치·운영 배포는 아직 하지 않았다.
